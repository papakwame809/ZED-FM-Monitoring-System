ZED FM Monitoring System — Quick User Guide
Welcome to the ZED FM Technical Monitoring System! This guide explains how to use the dashboard to log equipment, report on-air technical issues, and track routine maintenance.

Golden Rule
Always add equipment to the Asset Registry first!

Every incident report and maintenance log must be linked to a specific piece of equipment in the system.

How to Use the System
1. Asset Registry (Equipment List)
Where you keep track of all station hardware and gear.

Add New Equipment: Click the + Add Asset button at the top.

Fill in Details: Enter the equipment name, type (e.g., Audio Gear, Transmitter), and location (e.g., Studio 1, Rack Room).

Set Status: Pick the current state from the dropdown:

Operational — Working fine.

Under Maintenance — Currently being serviced.

Faulty / In Repair — Needs attention.

Dates: Use the built-in calendar pickers to record the purchase date and last service date.

2. Incident Reporting (Logging Faults)
Where you report on-air glitches, broken mics, or transmitter power drops.

Click on Incidents in the menu.

Click + Report Incident.

Select Asset: Click the dropdown menu and select the affected piece of equipment.

Select Severity:

Low: Minor issue, broadcast is unaffected.

Medium: Noticeable issue, but temporary workaround available.

High: Critical studio gear failing.

Critical: On-air dead air / main transmitter down.

Describe the Issue: Briefly explain what happened and pick the date/time of occurrence using the calendar picker.

Save: Submit the report so technical staff can resolve it.

3. Maintenance Records (Service Logs)
Where you record routine checks, repairs, and scheduled servicing.

Click on Maintenance.

Click + Log Service.

Select the equipment you are servicing from the dropdown list.

Choose the service type: Routine Check, Preventative, or Repair.

Pick the Service Date and set a Next Due Date using the calendar pickers.

Mark the repair status as In Progress or Completed.

Searching & Filtering
Search Bar: Type any keyword (e.g., "Studio A" or "Transmitter") to instantly filter lists.

Status Dropdowns: Filter items by operational status or incident urgency to focus on critical issues first.
